# Netflix Recommendation Engine
[Live Demo](https://netflix-recommendation-engine-nrqdzge5zdp5ddksrulpyz.streamlit.app/)
A movie recommendation system built using collaborative filtering and SVD. The project predicts movie ratings for a user and recommends the top 10 movies they are most likely to enjoy.

The project also includes a Streamlit web application with movie posters fetched from TMDB.
